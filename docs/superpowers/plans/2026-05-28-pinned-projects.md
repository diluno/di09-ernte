# Pinned Projects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the sidebar's automatic recency-based "Pinned" list with explicit, user-controlled project pinning.

**Architecture:** A nullable `pinned_at` timestamp on `projects` marks a project as pinned. The user toggles it from the Projects/Show header (`pin`/`unpin` routes mirroring the existing `archive` route). The sidebar shows only pinned **and** active projects, alphabetically. Archiving a project auto-unpins it. Recency stays covered by the existing localStorage "Recent" section, which is untouched.

**Tech Stack:** Laravel 12, Inertia v2, Vue 3, MariaDB (DDEV), Pest. Run tests with `ddev artisan test`; build assets with `ddev npm run build`.

**Spec:** `docs/superpowers/specs/2026-05-28-pinned-projects-design.md`

```php
    /** Projects the user has explicitly pinned (active only), alphabetical by name. */
    private static function pinnedProjects(): array
    {
        return Project::active()
            ->pinned()
            ->orderBy('name')
            ->get(['id', 'name', 'code', 'glyph'])
            ->map(fn ($p) => [
                'id' => $p->id,
                'name' => $p->name,
                'code' => $p->code,
                'glyph' => $p->glyph,
            ])
            ->all();
    }
```
